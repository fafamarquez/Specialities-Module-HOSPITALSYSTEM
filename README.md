# Specialities-Module-HOSPITALSYSTEM
Módulo de Medicina de Especialidad para el sistema hospitalario. Gestiona citas por referencia y seguimiento médico, interconsultas con Urgencias, programación y asignación de quirófanos, prescripción de fármacos controlados (NOM-024), docencia de residentes y control de honorarios médicos para más de 20 especialidades clínicas y quirúrgicas.
